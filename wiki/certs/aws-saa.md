## Key Architecture Areas

### VPC Design (connects to [[concepts/vpc-and-subnets]])
- Multi-AZ VPC design
- Public/private subnet architecture
- VPC Peering, Transit Gateway
- PrivateLink, VPC Endpoints

### Compute
- EC2 instance types, Auto Scaling Groups
- Launch Templates, AMIs
- ECS, EKS (Kubernetes — connects to k3s lab)
- Lambda + API Gateway

### High Availability
- Multi-AZ deployments
- ALB + Auto Scaling
- RDS Multi-AZ, Aurora
- S3 cross-region replication

### Security
- IAM roles, policies, least privilege
- KMS encryption at rest / in transit
- WAF, Shield, GuardDuty
- VPC Flow Logs, CloudTrail

### Cost Optimization
- Reserved Instances vs Spot vs On-Demand
- S3 storage classes (Standard, IA, Glacier)
- Right-sizing with Compute Optimizer
