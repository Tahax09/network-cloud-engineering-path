## Key Exam Facts (collected from sessions)

| Topic | Key Fact |
|-------|---------|
| Subnet route | Always wins — cannot be overridden by any custom route |
| Route priority | Specificity beats number; lower number wins ties; default = 1000 |
| Route + firewall | Both required for traffic to flow |
| Network tag | Scopes route to VMs with matching tag |
| Cloud Router | BGP-based; used with Interconnect and HA VPN; auto-updates |
| Subnet expansion | Irreversible; cannot shrink prefix |
| IPv6-only subnet | Does not exist in GCP |
| Dual-stack on auto mode | Not supported; must use custom mode |
| BYOIP minimum | /28 = 16 addresses |
| BYOIP idle IPs | Free (unlike Google-provided external IPs) |
| BGP specificity | Longer prefix (more specific) wins |
| Linux VM DNS | 169.254.169.254 — NOT an APIPA error |
| 8.8.8.8 | Recursive resolver, NOT authoritative for your domain |
| Failover routing policy | Private zones only |
| Routing policy limit | One type per record set |
| GEO nearest-match | Unmapped regions always get a response |
| Multiple NIC default route | nic0 only; other NICs need OS policy routing |
| NVA setup | --can-ip-forward + custom routes in both VPCs + OS policy routing |
| Private Google Access scope | Per subnet only; no effect on VMs with external IPs; Google APIs only |
| private vs restricted googleapis | private 199.36.153.8/30 (most APIs); restricted 199.36.153.4/30 (VPC-SC APIs only) |
| PGA for on-prem | VPN/Interconnect + DNS override + Cloud Router custom advertisement + VPC route → default-internet-gateway |
| Cloud DNS partial override | Not supported — use BIND |
| PSC | Endpoint → service attachment; no peering/route exchange; overlapping IPs OK; consumer-initiated only |
| PSC interface | Producer-initiated, transitive, uses network attachment |
| PSC endpoint caveats | Not reachable from peered VPCs; can't be in same VPC as the service |
| PSA | VPC Network Peering + allocated range; one range per producer; one connection per producer |
| PSA on-prem | Advertise allocated range + export custom routes on servicenetworking peering |
| PSA disable | Doesn't delete peering or release range |
| Cloud NAT | Outbound only; configured on Cloud Router; distributed (no proxy); manual IPs for allowlists |
| Cloud NAT + PGA | Google API traffic never NAT'd; PGA forced on for NAT'd ranges |
| Private NAT | Inter-VPC NAT between NCC spokes with overlapping ranges |
| IAP SSH | `gcloud compute ssh --tunnel-through-iap`; firewall allows TCP 22 only from 35.235.240.0/20; no bastion/external IP needed |
| NAT propagation | Up to ~3 min after gateway is Running |
| Network Service Tiers | Premium = Google backbone to PoP near user, global LB, higher cost; Standard = public internet, regional only, cheaper |
| Cloud Router | BGP for Interconnect, Cloud VPN, Router appliance; control plane for Cloud NAT (policy-based routes are a separate VPC feature) |
| Multi-region design | Mirror tiers per region with UNIQUE subnet ranges; LB to least-busy backend; per-tier firewall (prefer service-account rules) |
| Design process | Stakeholders → requirements → HLD → LLD (IP plan) → BoM (CapEx/OpEx) |
| Hub-and-spoke methods | Peering = low latency but NOT transitive; HA VPN + BGP = transitive, encrypted, more latency; NCC = centralized, transitive, extra cost |
| NCC spokes | VPC spokes (cross-project/org) + hybrid (HA VPN, Interconnect VLAN, router appliance VM); no IP overlap; no IPv6 on hybrid; PUPI ok |
| NCC lab result | Two isolated VPCs → VPC spokes on mesh hub → subnet routes exchanged → ping works without firewall changes |
| Mesh | Full = all↔all (GKE Enterprise microservices); partial = strategic links (cross-region failover); HA/scale/perf, but n(n−1)/2 links |
| Mirrored | Replica env/region for DR, dev/test, performance — unique IPs if ever connected |
| Gated | Gated egress (outbound from cloud), gated ingress (inbound to cloud), gated ingress+egress (both) — hybrid/multicloud control |
| Network Topology | Graph of entities + traffic; 6 weeks history, hourly snapshots; throughput, packet loss, median RTT; only nic0; no Cloud SQL/Memorystore/Filestore |
| PGA ranges (docs) | private 199.36.153.8/30 + IPv6 2600:2d00:0002:2000::/56; restricted 199.36.153.4/30 + 2600:2d00:0002:1000::/56; also route/allow 34.126.0.0/18 (direct connectivity) |
| NCC spoke types (docs) | VPC, producer VPC, NCC Gateway, hybrid; hybrid IPv6 = Preview; router appliance IPv4-only |
| NAT ports (docs) | 64,512 TCP + 64,512 UDP ports per NAT IP; Public NAT static by default, Private NAT dynamic by default |
| Centralized hybrid | Hybrid links in dedicated hub VPC; peer spokes with export/import custom routes + custom advertisement of spoke ranges → spoke↔on-prem (NOT spoke↔spoke) |
| Hybrid DNS | Two authoritative systems: Cloud DNS (GCP) + existing on-prem DNS, forwarding zones + inbound server policy |
| Expose apps | Through APIs via API gateway/LB; Apigee = security, rate limiting, quotas, analytics; LB + Apigee + CDN + Cloud Armor together |
| Interconnect encryption | Not encrypted by default → MACsec or HA VPN over Interconnect (or TLS) |
| Topology keywords | central mgmt → hub-and-spoke; all-to-all/HA → mesh; DR/dev-test copy → mirrored; strict security/isolate/specific APIs → gated |
| DDoS categories | Volumetric (bandwidth, Tbps) · protocol/state exhaustion (pps) · application L7 (rps) |
| Google scale | One data center ~1,300 Tbps bisection vs internet ~200 Tbps; Cloud Armor blocked 46M rps (2022) and 398M rps (Aug 2023) |
| DDoS mitigations | LB (built-in L3/L4; L7 LBs also stop Slowloris) · small attack surface (tier subnets, firewall, no public IPs, IAP) · VPN/Interconnect · Cloud CDN · Apigee · Cloud Armor |
| Cloud Armor | Edge WAF + DDoS; policy = ordered rules (condition, action, priority) on backend service; OWASP preconfigured rules, geo, rate-based ban, reCAPTCHA bots |
| IAM inheritance | Org → folder → project → resource; effective = union; child can't restrict parent; move project = new inheritance; deny policies checked first (docs: 500 per resource; lecture said 5) |
| Firewall rules | Stateful (return traffic auto, active if ≥1 pkt/10 min); priority 0–65535, default 1000, first match wins, same priority → deny wins; implied allow-egress/deny-ingress 65535 (not deletable); default VPC rules at 65534; SA targets > tags (IAM-controlled) |
| Firewall policies | Hierarchical (org/folder, goto_next) · global network (1 per VPC) · regional network (1 per region per VPC); secure tags; Cloud NGFW adds L7, FQDN, geo, IPS, threat intel; Firewall Insights = Monitoring metrics + Recommender |
| Networking roles | Network Viewer = read-only all networking · Network Admin = manage networking except firewall rules + SSL certs (read-only) · Security Admin = firewall rules + SSL certs · custom role when no fit |
| Cloud Armor rules (lab) | Default rule priority 2147483647 sets blocklist (allow) vs allowlist (deny); lower number first, first match wins; deny-403/404/502; attach to backend service; client IP in LB logs `httpRequest.remoteIp` (backends see GFE IPs) |
| Partner security categories | Data protection (DLP, DCAP, encryption, HSM) · Infrastructure protection (NGFW, WAF, proxy, DDoS, container) · Scanning/logging/monitoring (vuln scan, SIEM) · Identity/user (SSO, IAM, MDM/MAM, CASB) · Config/vuln/risk/compliance |
| Armor Standard vs Enterprise | Adaptive Protection, threat intel, named IP lists, advanced network DDoS = Enterprise; bill protection + DDoS response team = Enterprise Annual only |
| NAT logging | Translations and/or errors (port-exhaustion drops) → Cloud Logging, `resource.type="nat_gateway"` |
