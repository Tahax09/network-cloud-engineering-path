## Key AWS Services to Learn

### Compute
- EC2 (IaaS virtual machines)
- Lambda (serverless, PaaS)
- ECS / EKS (containers — connects to k3s knowledge)

### Storage
- S3 (object storage)
- EBS (block storage, EC2 volumes)
- EFS (file storage, NFS)

### Networking
- VPC, Subnets, Route Tables, IGW, NAT Gateway
- CloudFront (CDN — covered in L02)
- Route 53 (DNS)
- Direct Connect / Site-to-Site VPN

### Database
- RDS (managed relational — PaaS)
- DynamoDB (NoSQL)

### Security
- IAM (Identity & Access Management)
- Security Groups / Network ACLs
- WAF, Shield (DDoS protection)
- KMS (Key Management Service)
