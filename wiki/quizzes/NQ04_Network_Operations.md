## Answer Key

| # | Answer | Reasoning |
|---|--------|-----------|
| 1 | **B — Change Management** | Any change to production equipment (even a security update) requires a change request, approval, and documentation first |
| 2 | **A — Baseline configuration** | The standard approved config template provided so new switches are set up consistently |
| 3 | **B — CNAME** | Canonical Name record — creates an alias for an existing A record hostname |
| 4 | **D — Active-Passive** | One device active, one standby; passive only activates on primary failure |
| 5 | **A — Plan to decommission and replace** | EoS = no more patches; firmware update is impossible; isolation is a band-aid, not a fix |
| 6 | **B — Flow Data** | NetFlow/sFlow shows traffic sources, destinations, volumes, and protocols — ideal for identifying congestion cause |
| 7 | **A — TLS VPN** | Browser-based (clientless) SSL/TLS VPN; no client software required; accesses specific resources |
| 8 | **D — TXT** | TXT records are used for domain ownership verification (Google, Microsoft, domain registrars) and SPF/DMARC |
| 9 | **C — Asset Tags** | Physical tags (barcode/QR/RFID) on equipment enable inventory tracking and change auditing |
| 10 | **D — Physical** | Physical diagrams show physical cables and connector types including fiber (SC, LC, single-mode vs multi-mode) |
| 11 | **A — MTBF** | Mean Time Between Failures — measures operational duration before failure; MTTR is time to repair after failure |
| 12 | **B — Split-Tunnel** | Only corporate-bound traffic goes through VPN; internet/other traffic exits directly |
| 13 | **B — PTP** | Precision Time Protocol (IEEE 1588) — sub-microsecond accuracy; NTP only achieves millisecond precision |
| 14 | **B — Router is not sending Router Advertisements** | SLAAC requires RA messages from the router containing the IPv6 prefix; without RAs, no autoconfiguration occurs |
| 15 | **B — Port Mirroring** | SPAN/port mirroring copies all traffic on a port to a capture port; enables full packet inspection |
| 16 | **D — Jump Box** | Bastion/jump host — hardened public-facing server; admin SSHs in, then pivots to internal systems |
| 17 | **B + C — DNS over HTTPS + DNS over TLS** | Both encrypt DNS queries in transit; DNSSEC validates integrity but doesn't encrypt; SPF is email authentication |
| 18 | **A — Two hours** | RPO = max acceptable data loss = 2 hrs; RTO = max acceptable downtime = 4 hrs |
| 19 | **C — Reservation** | DHCP reservation = static binding of IP to MAC address; device always receives the same IP |
| 20 | **B — Router** | Routers (L3 devices) configured with `ip helper-address` relay DHCP broadcasts across VLANs to central server |
| 21 | **B — SNMP** | Simple Network Management Protocol — polls or receives data from managed devices (MIB counters, status) |
| 22 | **B — Service Level Agreement (SLA)** | SLA specifies vendor performance commitments: uptime, response time, resolution time |
| 23 | **C — Traps** | SNMP traps are unsolicited event notifications from device to manager when threshold/event occurs; get = polling |
| 24 | **A — Warm site** | Equipment ready but no live data sync; requires data restore from backup — between cold (no equipment) and hot (live mirror) |
| 25 | **B — Tabletop exercise** | Discussion-based walkthrough of roles and procedures; no actual execution; confirms awareness |
| 26 | **A — Log aggregation** | Collecting and centralizing logs from all systems into a single location (syslog server, SIEM) |

## Exam Traps

| Trap | Correct Thinking |
|------|-----------------|
| RPO vs RTO | **RPO = data loss** (how old can the restore be?); **RTO = downtime** (how fast must it be back?) — read the question carefully |
| MTBF vs MTTR | MTBF = time system runs before failure; MTTR = time to repair after failure |
| Hot vs Warm vs Cold site | Hot = live data mirror; Warm = equipment ready, no live data; Cold = just a building/power |
| Split-Tunnel vs Full-Tunnel | Split = only VPN-destined traffic tunneled; Full = all traffic goes through VPN |
| TLS VPN vs IPSec VPN | TLS VPN = browser-based, clientless, specific resources; IPSec = full client install, all traffic |
| Port Mirroring vs NetFlow | Mirroring = full packet contents captured; NetFlow = metadata/flow records only (not packet contents) |
| SNMP Get vs Trap | Get = NMS polls the device; Trap = device pushes an alert when something happens |
| DNSSEC vs DoH/DoT | DNSSEC = cryptographic signing for integrity; DoH/DoT = encryption in transit — different problems |
| PTP vs NTP | PTP (IEEE 1588) = sub-microsecond; NTP = millisecond; financial/5G/mobile → PTP |
| DHCP Reservation vs Exclusion | Reservation = assigns same IP to a MAC; Exclusion = removes IPs from pool so they're never assigned |
| Baseline config vs Logical diagram | Baseline config = standard device setup document; Logical = topology diagram |
| End-of-support response | Correct answer is always **replace** — you can't patch it, isolation is temporary, firmware doesn't exist |
| Jump Box vs VPN | Jump Box = publicly accessible bastion you connect TO first; VPN = tunnel from your device to the network |
