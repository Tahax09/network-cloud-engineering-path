## Answer Key

| Q | Answer | Key Reasoning |
|---|--------|--------------|
| 1 | **D — Datagram** | UDP (connectionless) PDU = datagram; TCP (connection-oriented) = segment |
| 2 | **A — It relies upon other layers for packet delivery** | L7 uses all layers below for transmission — no translation, encryption, or independent error-checking |
| 3 | **D — Switch** | Operates at L2 + L3; hub and transceiver are L1-only |
| 4 | **A — Datagram** | Same concept as Q1 — UDP connectionless transport = datagram |
| 5 | **A — Switch** | Switches support jumbo frame MTU configuration (up to 9000 bytes) |
| 6 | **B — Access point** | APs extend WLAN coverage for wireless clients |
| 7 | **B — IPS** | Inline + blocks = IPS; IDS is passive/out-of-band (detects and alerts only) |
| 8 | **D — Layer 3 switch** | Access ports (L2) + routing capability (L3) — both described in the question |
| 9 | **B — QoS** | Quality of Service classifies and prioritizes traffic by type |
| 10 | **A — Quality of service** | QoS gives priority to latency-sensitive real-time traffic (voice/video) |
| 11 | **B — CDN** | Content Delivery Network = geographically distributed PoPs, reduced latency |
| 12 | **B — Hybrid** | On-prem for key services + cloud for others = hybrid deployment model |
| 13 | **D — Direct Connect** | Dedicated physical link to cloud provider with no built-in encryption (VPN adds encryption) |
| 14 | **B — Infrastructure as a Service** | IaaS requires the most migration effort — you manage VMs, OS, and storage yourself |
| 15 | **C — Network Security Group** | NSGs apply to specific VMs/NICs; NACLs/Security Lists apply to whole subnets |
| 16 | **B — Network Function Virtualization (NFV)** | NFV = virtual appliances replacing physical network devices |
| 17 | **A — IPSec VPN** | Encrypted tunnel over public internet between offices with different ISPs |
| 18 | **A — ESP (Encapsulating Security Payload)** | ESP encrypts payload; AH provides only integrity/authentication — no encryption |
| 19 | **A — SSH** | TCP port 22, encrypted remote access |
| 20 | **B — Multicast** | Multicast = group of nodes (some); anycast = nearest one; broadcast = all |
| 21 | **C — 587** | SMTP submission with TLS; 25 = relay, 110 = POP3, 143 = IMAP |
| 22 | **B — ICMP** | Ping and unreachable messages; not TCP/UDP (transport), not SNMP (management) |
| 23 | **B — 802.11 WiFi technologies** | 802.11n/ac/ax all support both 2.4 GHz and 5 GHz |
| 24 | **C — Heat Map** | Wireless heat map shows signal coverage to choose optimal AP placement |
| 25 | **D — 802.11ax (Wi-Fi 6)** | Highest user density (OFDMA, MU-MIMO) + supports 2.4, 5, AND 6 GHz |
| 26 | **B — Multimode Fiber** | MMF large core = light reflects at multiple angles off cladding; SMF = single straight path |
| 27 | **A — GBIC** | GBIC (Gigabit Interface Converter) is the transceiver module interface on fiber NICs |
| 28 | **C — SFP** | Small Form-factor Pluggable = modular, hot-swappable, supports multiple media types and speeds |
| 29 | **C — Mesh** | Full mesh = direct link between every node in the network |
| 30 | **D — Access, distribution, core** | End-stations connect at access → aggregate at distribution → backbone at core |
| 31 | **A — Flow of data from the internet into and out of the cloud** | North-south = external ↔ internal; east-west = server ↔ server inside the DC |
| 32 | **A — 255.255.255.248** | /29 = 2³−2 = exactly 6 usable hosts — minimum waste; /30 = 2 hosts, /28 = 14 hosts |
| 33 | **C — The IP address is reserved and will not route through the internet** | 10.0.0.0/8 is RFC 1918 private; .97 is a valid host (not APIPA, not loopback) |
| 34 | **B — Control Plane** | SDN centralizes routing decisions in a controller; data plane stays distributed in devices |
| 35 | **D — Software Defined Networking** | SDN controller pushes forwarding logic to devices programmatically |
| 36 | **C — VXLAN** | L2 overlay over L3 IP; 24-bit VNI supports 16 million segments |
| 37 | **A + B — Mutual Authentication + Micro-segmentation** | Zero Trust = verify identity (mutual auth) + restrict lateral movement (micro-seg); IPS/IDS are not ZT concepts |
| 38 | **C — Least privilege** | Minimum access needed for the task |
| 39 | **D — CASB** | Cloud Access Security Broker = visibility and policy enforcement across SaaS/IaaS |
| 40 | **B — All of the above** | SSE (Security Service Edge) includes CASB, SWG, ZTNA, and Firewall-as-a-Service |
| 41 | **A — API** | APIs enable programmatic/automated management; SSH/CLI/GUI are manual |
| 42 | **C — Conflict resolution** | Resolves the problem of conflicting changes to the same code from multiple contributors |
| 43 | **A — Tunneling** | Encapsulates IPv4 inside IPv6 packets; dual stack runs both simultaneously (different use case) |

## Exam Traps in This Quiz

| Trap | Detail |
|------|--------|
| Q1 = Q4 | Same question, different wording — both answer is Datagram |
| AH vs ESP | AH = integrity only; ESP = encryption + integrity. Exam loves this |
| Direct Connect = no encryption | Dedicated link but no built-in crypto — VPN adds that layer |
| Anycast ≠ "some nodes" | Anycast = nearest single node; Multicast = group of nodes |
| /29 for 6 hosts | 2³−2 = 6 exactly — don't over-provision to /28 (14 hosts) |
| IPS/IDS are not Zero Trust | ZT = mutual auth + micro-segmentation. IPS/IDS are detection/prevention tools |
| NFV vs SDN | NFV = virtual appliances; SDN = centralized control plane. Different concepts |
| North-south vs East-west | North-south = in/out of DC (internet); East-west = within DC (server-to-server) |
