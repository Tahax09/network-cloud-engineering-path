    What the lab proves
    
    
    
      
    Blocked at the POP
    Denied requests never cross the backbone or enter your VPC, so they use no backend capacity.
    
      
    The default rule sets the type
    Default allow plus deny rules is a blocklist. Default deny plus allow rules is an allowlist. The default rule has priority 2147483647.
    
      
    Changes take a few minutes
    A new policy reaches each POP separately. That's why the lab says you may still see the page at first.
    
      
    Find the client IP in the logs
    Use httpRequest.remoteIp. Backends see GFE addresses (35.191.0.0/16, 130.211.0.0/22), because the GFE opens its own connection to them.
    
    
    
    
    IP addresses come from documentation ranges, and the zones are examples. Request rates are scaled down for the animation, and each backend is modeled with room for 8 requests per second.
